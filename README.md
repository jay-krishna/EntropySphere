# Entropy Sphere

A privacy-friendly password generator that runs entirely in the browser and can be installed as an app. Nothing you type or generate ever leaves your device, there is no backend and no analytics.

- Secure randomness and unbiased sampling
- Adjustable length (1–100) with sliders and manual input
- Toggle uppercase, lowercase, numbers, and symbols (editable symbol set)
- "No similar" mode (skips look-alikes) and "Unique" mode (no repeated characters)
- Live strength and entropy readout with colour-coded feedback
- Light and dark themes; works as an installable PWA on supported platforms

## Installing the app

- Android (Chrome/Edge): an install button appears in the header, or use the browser menu → Install app.
- iOS/iPadOS (Safari): Share → Add to Home Screen.
- macOS/Windows (Chrome/Edge): the install button appears in the header, or use the install icon in the address bar.

## Offline behaviour

The app shell is cached on first visit so the app opens offline afterwards. If fonts haven't been cached yet, the app falls back to system fonts but remains fully functional.
